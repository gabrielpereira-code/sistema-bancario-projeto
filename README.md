# Sistema Bancário em Python

Projeto de estudo que simula operações básicas de um banco, executado no terminal.

## Funcionalidades
- Depositar
- Sacar
- Consultar extrato
- Sair

## Tecnologias
- Python 3

## Como executar
1. Instale o Python 3
2. Baixe os arquivos deste repositório
3. No terminal, dentro da pasta do projeto, rode:
   python main.py
