# Sistema Bancário em Python

Projeto de estudo que simula operações bancárias básicas pelo terminal.

## Funcionalidades
- Depósito (apenas valores positivos)
- Saque com limite de R$ 500,00 por operação e máximo de 3 saques diários
- Extrato com histórico de movimentações e saldo atual
- Validação de saldo insuficiente e de valores inválidos

## Tecnologias
- Python 3

## Como executar
1. Instale o Python 3
2. Baixe os arquivos deste repositório
3. No terminal, dentro da pasta do projeto, execute:
   python sistema_bancario_projeto.py
